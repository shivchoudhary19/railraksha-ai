# 0001 — Foundation and phase boundaries

Accepted, 2026-10-12. The supplied master prompt is the scope authority.

Use the requested Next.js 15/React 19 and Python 3.12/FastAPI stacks in a pnpm/Turborepo monorepo. Shared UI and Zod input definitions are small workspace packages. PostgreSQL stores profiles and audit events. Redis stores short-lived sessions and sliding-window request limits. Docker Compose is the single local startup path.

Only Phase 1 is implemented. The dashboard and operator workspace show real empty states. No registry, scan, verdict, upload, chatbot, payment or future-service scaffold exists. Data-fetching and chart libraries are deferred until a phase needs them. The public site identifies itself as an independent development project.

Public content uses server components, local SVG art and system fonts. English/Hindi messages have the same keys. Accessible green text is darker than the brand signal green; dark-theme tokens are independent. There are no tracking scripts or remote font requests.

This is a local development stack. Production TLS, real operator/contact identities, retention operations, backups and an independently verified ASVS/WCAG compliance assessment are deployment obligations; the implementation does not claim certification.
